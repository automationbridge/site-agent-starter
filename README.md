# My website pages

This is your website's project folder. Claude reads the instructions in it every time you start a chat, then builds
and publishes pages to your WordPress site for you.

- **To make or change a page:** open https://claude.ai/code, pick this repository, and describe what you want.
- **To give Claude images:** add them to the `images` folder (Add file, then Upload files).
- **Your pages:** a copy of each one is kept in the `pages` folder.

Your website password is never stored here. It lives only in Claude Code's environment settings. To cut Claude off at
any time, go to Site Agent, then Settings in WordPress, and press Disconnect.
